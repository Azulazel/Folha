# Folha — leitura confortável

Leitor de PDFs para celular, com texto adaptável, letras ajustáveis, temas, reconhecimento de páginas escaneadas e exportação de uma cópia para leitura.

## Abrir o site

**https://azulazel.github.io/Folha/**

## Arquivos

- `index.html`: aplicativo web completo, com código, estilos, fontes e bibliotecas incorporados. Pode ser baixado e aberto no navegador.
- `Folha-codigo-e-Android.zip`: código organizado e projeto Android com Capacitor, incluindo fontes editáveis, dependências e configuração para Android Studio.
- `COMO-PUBLICAR-FOLHA.md`: instruções para compilar, testar, assinar e enviar o aplicativo à Google Play.

Os PDFs são processados no aparelho. O OCR precisa de internet para baixar os componentes e idiomas. A cópia adaptada contém texto; consulte o original para imagens, tabelas e diagramação.

O projeto Android ainda precisa ser compilado e testado em um celular ou emulador; o ZIP não contém um APK/AAB assinado. As licenças das bibliotecas e fontes estão incluídas no pacote.
